# Roles: a review of agents that carry a proof of reliability

A literature review for `Tewf/roles`, read on 2026-11-16: what the field calls a role, how autonomy is graded, what counts as a proof of reliability, and how roles are packaged and served. It ends on a named baseline, B1, and on the position: the reliability proof as what the searches did not find combined.

**Shape:** [review](https://github.com/Tewf/reader-ergonomics-review/blob/39d3b25cd822a20277ee39c37b9e0130439802f2/shapes/README.md), the nine files of reader-ergonomics-review.

## The answer

A role as the field ships it (a prompt persona, an SOP, a `SKILL.md` skill) carries no reliability statement. The nearest work proves that a skill stays inside its declared capabilities (Metere 2026b), not that it does its task, and a Lean proof closed an autonomous result in one case (Ju 2026). No source in these searches gives a role a Lean theorem, a success rate with an interval and references together.
